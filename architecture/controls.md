# Controls: quick bar and hotkeys

The quick bar is a floating composer summoned with a global hotkey. `Ctrl+Shift+1..9` applies presets 1 to 9. Both are set on Interface → Quick bar.

- Hotkeys are registered with the OS (`RegisterHotKey`) without low-level keyboard hooks. Global hotkeys are Windows only.
- The main window and the quick bar can each be hidden from recording, with **Hide main window from recording** and **Hide quick bar from recording**.
