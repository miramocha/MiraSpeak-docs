# Controls: quick bar and hotkeys

The quick bar is a floating composer summoned with a global hotkey. Set that hotkey on Interface → Quick bar. `Ctrl+Shift+1` through `Ctrl+Shift+9` apply presets 1 to 9. `Ctrl+Alt+1` through `Ctrl+Alt+9` activate the first 9 personas. Those chords are fixed.

- Hotkeys are registered with the OS (`RegisterHotKey`) without low-level keyboard hooks. Global hotkeys are Windows only.
- The main window and the quick bar can each be hidden from recording, with **Hide main window from recording** and **Hide quick bar from recording** on Interface → Quick bar.
