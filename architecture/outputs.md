# Outputs: audio devices and text output

Both live under **Output** in settings.

## Audio Devices

Picks the Output device and an optional Monitor copy, and can create a virtual output for OBS. See [Layers](layers.md#audio-and-mouth) and the [quick start](../guides/quick-start.md).

## Text Output

Writes the currently playing line to a text file for stream overlays. The write is atomic, and the file clears a couple of seconds after playback goes idle. When a line was [translated](translation.md), the caption can be the translated text (default), the original, or both.
